# 快速上手(5 分钟验收)

## 打开面板

1. 侧栏底部点击 **Git** 按钮(带改动数徽标);
2. 右侧出现浮动面板,五个标签页:变更 / 日志 / 分支 / 储藏 / AI 修改。

## 体验一次完整流程

1. 让 Agent 修改任意文件 → 面板在 ~2s 内出现该文件(状态字母:M=修改、A=新增、D=删除、?=未跟踪);
2. 点击文件查看行级 diff(绿色新增 / 红色删除);
3. 点击状态字母把文件**暂存**,在提交框输入信息后 **提交**;
4. 「分支」页新建 `demo` 分支、切回 `master`、把 `demo` 合并进来;
5. 「日志」页可对任一提交 **撤销 (revert)**;
6. 「AI 修改」页显示每个会话/轮次改过的文件,点击跳转 diff。

## 危险操作都有确认弹窗

丢弃改动、删除未跟踪文件、hard reset、删除储藏 —— 都会先弹窗确认,失败会显示结构化错误原因(锁、冲突、身份缺失、认证失败等)。

## 开发迭代

```powershell
cd dsh-git-gui
node scripts/build-client.mjs --watch   # 改 client-src 后自动重建,刷新页面生效
node --test tests/                      # 38 项测试
```

Host(`lib/`)改动需重启 `dsh web`。
